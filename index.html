Wipeout 3 Data Exploration

Diving deep into the PS1 classic's game data

About This Project

Welcome to my exploration of Wipeout 3's game data. This project documents my journey through reverse engineering and analyzing the data structures, assets, and inner workings of this iconic PlayStation racing game.

Areas of Exploration

Track Data

Analysis of track geometry, collision data, and how the game constructs its futuristic racing circuits.

Ship Models

Examination of vehicle models, textures, and performance characteristics stored in the game files.

Audio Systems

Understanding how the game handles its iconic soundtrack and sound effects.

Game Physics

Uncovering the physics parameters that make Wipeout's anti-gravity racing feel unique.
